# References to study and cite

Verify each repository (existence, licence, last release) before citing.

## Standards and guidance
- NIST SP 800-101 Rev. 1, Guidelines on Mobile Device Forensics
- NIST CFTT mobile device tool test specification
- ISO/IEC 27037 and ISO/IEC 27042
- SWGDE best practices for mobile device forensics

## Open-source tools
- ALEAPP and iLEAPP (abrignoni): artifact parsers for Android and iOS
- AndroidQF and MVT (mvt-project): Android acquisition and spyware checks (MVT has its own licence)
- libimobiledevice: iOS backup and file services
- pymobiledevice3: Python iOS device access
- wa-crypt-tools: WhatsApp backup decryption
- Autopsy / The Sleuth Kit: case management and file system analysis
- sqlite-dissect and Undark: SQLite deleted-record recovery

## Papers and talks
- Brignoni, ILEAPP and ALEAPP: parse and validate mobile forensic artifacts with Python (DFRWS USA 2020)
- Vendor documentation (Cellebrite, Oxygen, Magnet) for acquisition-method terminology
